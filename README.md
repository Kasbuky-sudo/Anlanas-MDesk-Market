# Anlanas's MDesk Market

M·Desk 三方订阅源（纯静态目录）。

## 源地址

添加到 M·Desk：**应用中心 → 三方订阅源 → 管理订阅**。

```text
https://raw.githubusercontent.com/Kasbuky-sudo/Anlanas-MDesk-Market/main/
```

## 收录

| 应用 | packageId | 版本 | 架构 |
|---|---|---|---|
| 米游签 | `mdesk.miyouqian` | 1.0.5 | amd64 / arm64 |
