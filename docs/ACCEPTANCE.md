# 新应用验收清单

发布前逐项勾选；未在真机验证的项不要勾。x86 与 arm64 包分别验收。

## 构建

- [ ] `manifest` 的 `appname`、`version`、`platform`、`service_port` 与实际包一致
- [ ] 包内没有官方安装包、`node_modules` 构建残留、`dist/`、`.build-staging/`
- [ ] `.node` 与可执行文件的架构检查通过（x86 包无 aarch64；arm64 包无 x86-64）
- [ ] Node 原生模块 ABI 与运行时一致（Node 22 → 127）
- [ ] `fnpack build` 成功，产物名符合 `<app-id>-<version>-<arch>.fpk`
- [ ] 记录 `sha256sum` 与文件大小

## 安装

- [ ] 在干净的飞牛环境安装，依赖（如 `nodejs_v22`）自动安装/启用
- [ ] 安装向导可完成，必填项校验生效
- [ ] `config/resource` 声明的共享目录已创建
- [ ] 桌面图标存在，入口端口与 `service_port` 一致

## 启动与停止

- [ ] 首次启动成功，端口进入 `LISTEN`
- [ ] 停止后进程退出、端口释放
- [ ] 连续启动/停止/重启 3 次无残留进程
- [ ] 系统重启后应用能自动启动
- [ ] `var/info.log`、适配层日志无未处理异常

## 功能

- [ ] 登录流程可完成（弹窗被拦截时有兜底入口）
- [ ] 核心动作可完成（发送消息、上传/下载、保存等）
- [ ] 刷新页面后会话与登录态保持
- [ ] 从另一台设备访问，数据与工作区一致
- [ ] 手机端 / 飞牛 App 能识别设备在线（涉及 edge-sync 的应用）

## 升级与卸载

- [ ] 覆盖升级成功，令牌、配置、工作区数据保留
- [ ] 升级后生命周期脚本恢复可执行位，CLI 可运行
- [ ] 卸载后应用进程停止，端口释放
- [ ] 卸载不会误删用户共享目录（按应用约定）

## 安全

- [ ] 未携带令牌访问时返回 401，不泄露内部路径
- [ ] 令牌只存在于 `TRIM_PKGVAR/etc/`，权限 `0600`
- [ ] 日志与文档中无内网 IP、令牌、Cookie、账号信息
- [ ] 默认只监听局域网，未建议用户直接暴露公网
- [ ] 第三方应用 README 已注明非官方移植与版权归属
